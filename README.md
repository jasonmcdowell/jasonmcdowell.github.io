# Dream Houses

Public browser builds of interactive house studies.

The live site is published with GitHub Pages at:

https://jasonmcdowell.github.io/

The root walkthrough is the current Dream Home v07 study. Future buildings can live in their own folders, such as `brother-house/`, and be linked from the site.

## Contributing a building

Fork this repository, add a self-contained building folder with an `index.html`, its assets, and any supporting JavaScript/CSS, then open a pull request. Keep individual files below GitHub's 100 MiB repository-file limit and keep the published site suitable for a static browser host.
