# jasonmcdowell.github.io · personal showcase

This public repository hosts the GitHub Pages homepage at [jasonmcdowell.github.io](https://jasonmcdowell.github.io/).

## What is published

- The root page is Jason’s personal project showcase.
- Project tiles link to their own public sites and repositories.
- The Dream Home walkthrough lives in the separate [Dream Home Walkthrough repository](https://github.com/jasonmcdowell/dream-home-walkthrough).

## Where the source lives

- The **Personal Webpage** project owns the root `index.html`, `site.css`, and showcase assets.
- The public copies are assembled here for GitHub Pages.
- `publish-to-pages.sh` in the Personal Webpage project copies only the homepage files here. It does not commit or push automatically.

This repository intentionally does not contain the Dream Home walkthrough files. The homepage links to the project site at [jasonmcdowell.github.io/dream-home-walkthrough](https://jasonmcdowell.github.io/dream-home-walkthrough/).
